# OpenCV 光电视觉自学路线

这是为光电信息科学与工程学生设计的 OpenCV 自学路线，主线为 Python → NumPy/Matplotlib → OpenCV → 传统机器视觉 → 相机成像与标定 → C++/AI/3D视觉。

## 使用

直接打开 `index.html` 即可。勾选项会保存在浏览器 localStorage 中。

## 推荐节奏

每周 6～8 小时，坚持 5～6 个月。每次学习按照：20% 理论 + 50% 写代码 + 30% 小任务/复盘。

## 阶段

0. Python 补强：函数、容器、文件、环境管理
1. NumPy + Matplotlib：数组和实验数据分析
2. OpenCV 基础：图像读写、颜色空间、ROI、滤波、阈值
3. 传统机器视觉：边缘、轮廓、形态学、霍夫、测量
4. 相机与成像：标定、畸变、透视、光学成像因素
5. 工程化与进阶：Git、C++、PyTorch、YOLO、3D视觉

## 推荐资源

- OpenCV: https://github.com/opencv/opencv
- opencv-python: https://github.com/opencv/opencv-python
- Computer Vision Basics: https://github.com/jrobchin/Computer-Vision-Basics-with-Python-Keras-and-OpenCV
